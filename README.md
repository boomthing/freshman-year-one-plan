# 大一抢跑班 Landing Page

轻量静态网页，使用 HTML、CSS 和少量 JavaScript，无前端运行依赖、无外部字体或图片请求。

## 打开网页

直接使用浏览器打开 `dist/index.html` 即可。也可以将 `dist` 目录作为静态站点部署。

## 文件说明

- `dist/index.html`：全部课程文案、11 个内容 Section、价格和免责声明。
- `dist/styles.css`：桌面、平板、手机布局，以及文件末尾的 A4 打印样式。
- `dist/script.js`：调用浏览器打印和未配置咨询方式时的提示。

导航与首屏按钮使用原生锚点，关闭 JavaScript 后仍可使用。平滑滚动尊重系统减少动态效果设置。

## 导出 PDF

点击桌面导航栏“打印 / 保存PDF”，或使用浏览器打印快捷键 Ctrl+P（macOS 为 Command+P）。

推荐设置：

- 目标：另存为 PDF。
- 纸张：A4，纵向。
- 缩放：100%。
- 启用背景图形，关闭浏览器页眉和页脚。
- 保持页面定义的边距；不要自定义大边距。

打印样式将内容分为 7 组：首屏与大一价值、课程总览、6 次 1V1、高数英语与 Bonus、适合人群与产品逻辑、独立价格页、最终总结与免责声明。

已使用 Windows Edge 的打印引擎生成并逐页检查附带 PDF。其他浏览器或本机字体设置可能造成细微换行差异。

## 替换微信二维码

当前两个二维码区域均明确标为“待提供”，没有伪造可扫描二维码或联系方式。

1. 将真实二维码图片放入 `dist`，例如 `wechat-qr.png`。
2. 将 `index.html` 中两处 `.qr-placeholder` 容器替换成真实图片，保留对应 class，并设置 `alt="微信课程咨询二维码"`。使用正方形图片，并保留二维码四周白边。
3. 删除对应“二维码待配置”文案。
4. 更新 `script.js` 中 `[data-consult]` 的点击处理，让用户查看或保存真实二维码；删除目前未配置提示。
5. 重新用手机扫码验证，并重新导出 PDF。
